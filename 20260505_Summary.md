#### 4. New script: `split_epub_chapters.ps1`
Created a PowerShell script to split an EPUB by chapter count with auto-formatted titles.

**Parameter order:**
| Position | Parameter | Required | Default |
|----------|-----------|----------|---------|
| 0 | `EpubFile` | yes | — |
| 1 | `StartIndex` | no | 1 |
| 2 | `EndIndex` | no | 0 (unlimited) |
| 3 | `ChaptersPerSplit` | yes | — |
| 4 | `TitlePattern` | yes | — |

- Title pattern uses `xxxx`/`yyyy` as zero-padded placeholders for first/last chapter number.
- Detection patterns overridable via `$env:esP1` / `$env:esP2`.

**Bugs fixed during development:**
- `$pId` renamed to `$pIdPat` — conflicts with PowerShell's read-only `$PID` built-in.
- `$StartIndex:` / `$EndIndex:` in strings wrapped as `${StartIndex}:` / `${EndIndex}:` — colon after variable name was misread as drive specifier.
- `html5lib` installed into venv (was missing, caused `FeatureNotFound` error in BeautifulSoup).
